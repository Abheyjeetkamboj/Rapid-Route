# RapidRoute AI

**AI-Powered Ambulance Dispatch Optimiser**

> *Fastest suitable ambulance, not simply nearest ambulance.*

RapidRoute AI is an emergency medical dispatch platform designed for emergency dispatch centres, hospital networks, government EMS operations, and private ambulance networks.

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Lucide React (icons)
- React Router DOM

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)
